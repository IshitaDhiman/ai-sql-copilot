# Business Domain

## Project Overview

Enterprise AI SQL Copilot is an AI-powered application that converts natural language questions into SQL queries and executes them on a relational database.

The application uses a Retail Banking database as the demonstration dataset.

---

## Objectives

- Convert natural language to SQL
- Understand database schema
- Execute generated SQL
- Validate SQL correctness
- Improve SQL generation using AI techniques

---

## Business Domain

The database represents a Retail Banking System containing:

- Customers
- Accounts
- Loans
- Transactions
- Credit Cards
- Fixed Deposits
- Branches
- Employees

---

## Target Users

- Business Analysts
- Database Administrators
- Data Analysts
- Non-technical Business Users
